## Теоретическая справка

### Как bash считает

Bash — это **командная оболочка**, а не язык программирования в привычном смысле. Числа в нём по умолчанию — это **строки текста**. Чтобы bash понял, что нужно выполнить математику, ему нужно об этом сказать явно.

Есть **четыре** основных способа считать в bash:

| Способ | Синтаксис | Когда использовать |
|---|---|---|
| Арифметическое расширение | `$((2 + 2))` | **Основной способ**, работает везде |
| Команда `expr` | `expr 2 + 2` | Устаревший, но встречается в старых скриптах |
| Двойные скобки | `((x = 2 + 2))` | Когда нужно изменить переменную |
| `bc` | `echo "2 + 2" \| bc` | Для дробных чисел |

**Мы будем использовать `$(( ))`** — это стандарт, работает быстро, поддерживает всё, что нужно.

### Что умеет `$(( ))`

```bash
$((5 + 3))     # сложение → 8
$((10 - 4))    # вычитание → 6
$((6 * 7))     # умножение → 42
$((20 / 4))    # деление → 5
$((17 % 5))    # остаток от деления → 2
$((2 ** 10))   # возведение в степень → 1024
```

### Важные правила

- **Целые числа только.** `$((10 / 3))` вернёт `3`, а не `3.33`. Дробные — через `bc`.
- **Пробелы вокруг операторов желательны.** `$((5 + 3))` — хорошо, `$((5+3))` — тоже работает, но `$((5+ 3))` может сломаться.
- **Переменные внутри без `$`.** Внутри `$(( ))` можно писать `a + b` вместо `$a + $b` — bash поймёт.

## Часть 0. Работа с редактором nano (10 минут)

Прежде чем создавать скрипты, нужно научиться пользоваться редактором. В Linux для новичков удобнее всего **nano** — он простой и показывает подсказки внизу экрана.

### Как открыть файл в nano

```bash
nano имя_файла.sh
```

Если файла нет — nano создаст его. Если есть — откроет для редактирования.

### Как сохранить и выйти: три главных действия

После того как набрали код, нужно:

| Шаг | Клавиши | Что происходит |
|---|---|---|
| **1. Сохранить** | `Ctrl + O` | nano спросит: «File Name to Write: имя_файла.sh» |
| **2. Подтвердить** | `Enter` | Файл записывается на диск |
| **3. Выйти** | `Ctrl + X` | nano закрывается, вы возвращаетесь в терминал |

**Мнемоника:**
- `Ctrl + O` — **O**utput (вывод в файл, сохранение).
- `Ctrl + X` — e**X**it (выход).

> 💡 **Проверьте себя:** после `Ctrl+O` внизу появится строка `File Name to Write: ...`. Если нажать `Enter`, файл сохранится. Если случайно нажали `Ctrl+X` **до** сохранения — nano спросит: «Save modified buffer? (Y/N)». Можно нажать `Y`, потом `Enter` — сохранит и выйдет.

### Другие полезные клавиши в nano

| Клавиши | Действие |
|---|---|
| `Ctrl + O`, `Enter` | Сохранить и продолжить редактирование |
| `Ctrl + X` | Выйти |
| `Ctrl + K` | Вырезать строку |
| `Ctrl + U` | Вставить вырезанное |
| `Ctrl + W` | Поиск |
| `Ctrl + G` | Помощь |

### Опасность: если выйти без сохранения

Если набрали код и нажали `Ctrl+X` без `Ctrl+O`, nano спросит:

```
Save modified buffer?
 Y Yes
 N No
^C Cancel
```

- `Y` — сохранить, потом спросит имя файла, нажмите `Enter`.
- `N` — выйти **без** сохранения (все набранное потеряется).
- `Ctrl+C` — вернуться к редактированию.

Затем откройте снова (`nano test_nano.txt`) и убедитесь, что текст на месте. Выйдите через `Ctrl+X` (на этот раз nano ничего не спросит, так как нет изменений).

## Часть 1. Как создать и запустить скрипт (10 минут)

### Шаг 1. Открыть терминал

`Ctrl+Alt+T` (или через меню «Пуск»).

### Шаг 2. Создать рабочую папку

```bash
mkdir -p ~/bash_math
cd ~/bash_math
```

**Разбор:**
- `mkdir -p` — создать папку. `-p` значит «не ругаться, если уже есть» и «создать все промежуточные папки».
- `~/bash_math` — папка в домашней директории пользователя.
- `cd` — перейти в неё.

### Шаг 3. Создать файл скрипта

```bash
nano 01_hello.sh
```

Откроется редактор `nano`. Введите:

```bash
#!/bin/bash
# Мой первый скрипт
echo "Привет! Скрипт работает."
```

**Разбор первой строки:**
- `#!/bin/bash` — **шебанг**. Говорит системе: «выполняй этот файл через `/bin/bash`». Без него Linux не поймёт, чем интерпретировать файл.
- `#` — комментарий. Всё после него до конца строки bash игнорирует.
- `echo` — команда, печатающая текст в терминал.

### Шаг 4. Сохранить файл — три шага

В редакторе nano:

1. **`Ctrl + O`** — nano спросит имя файла внизу экрана.
2. **`Enter`** — подтвердить имя. Файл записан.
3. **`Ctrl + X`** — выйти из редактора.

**Проверка:** после выхода вы снова видите приглашение терминала (`user@pc:~/bash_math$`).

> ⚠️ **Самая частая ошибка новичка:** набрать код, нажать `Ctrl+X` (не сохранив), ответить `N` (не сохранять) — и потерять всю работу. **Всегда сначала `Ctrl+O`, потом `Enter`, потом `Ctrl+X`.**

### Шаг 5. Сделать файл исполняемым

Проверить текущие права:

```bash
ls -l 01_hello.sh
```

Вы увидите что-то вроде `-rw-r--r--` — **нет буквы `x`** (execute = выполнение). Дать право:

```bash
chmod +x 01_hello.sh
```

Проверить:

```bash
ls -l 01_hello.sh
```

Теперь `-rwxr-xr-x` — есть `x`.

### Шаг 6. Запустить скрипт

```bash
./01_hello.sh
```

**Разбор:**
- `.` — текущая папка.
- `/` — разделитель.
- `01_hello.sh` — имя файла.
- Вместе `./01_hello.sh` = «запусти файл `01_hello.sh` из текущей папки».

**Почему не просто `01_hello.sh`?** Linux ищет программы в системных папках (`/bin`, `/usr/bin` и т.д.), а не в текущей. `./` говорит: «ищи здесь».

**Ожидаемый вывод:**
```
Привет! Скрипт работает.
```

### Шаг 4. Усложним — все операции

Создайте `03_all_ops.sh` (`nano 03_all_ops.sh`):

```bash
#!/bin/bash
# Все основные арифметические операции

a=17
b=5

echo "a = $a"
echo "b = $b"
echo "---"

# Сложение
echo "Сложение:        $a + $b = $((a + b))"

# Вычитание
echo "Вычитание:       $a - $b = $((a - b))"

# Умножение
# Звёздочку НЕ нужно экранировать внутри $(( ))
echo "Умножение:       $a * $b = $((a * b))"

# Деление (целочисленное!)
# 17 / 5 = 3, а не 3.4 — bash работает с целыми
echo "Деление:         $a / $b = $((a / b))"

# Остаток от деления
# 17 % 5 = 2, потому что 17 = 3*5 + 2
echo "Остаток:         $a % $b = $((a % b))"

# Возведение в степень
# 2 ** 10 = 1024
echo "Степень:         2 ** 10 = $((2 ** 10))"
```

**Сохранить:** `Ctrl+O`, `Enter`, `Ctrl+X`.

```bash
#!/bin/bash
# Счётчик с разными способами увеличения

count=0

# Способ 1: через $(( ))
count=$((count + 1))
echo "После первого увеличения: $count"

# Способ 2: сокращённая запись
# (( count++ )) — то же самое, что count=$((count + 1))
(( count++ ))
echo "После второго увеличения: $count"

# Способ 3: прибавить сразу 5
(( count += 5 ))
echo "После += 5: $count"

# Способ 4: умножить
(( count *= 2 ))
echo "После *= 2: $count"
```

```
После второго увеличения: 2
После += 5: 7
После *= 2: 14
```

**Разбор сокращений:**
- `(( count++ ))` — увеличить на 1.
- `(( count += 5 ))` — увеличить на 5 (аналог `count = count + 5`).
- `(( count *= 2 ))` — умножить на 2.

## Часть 4. Ввод чисел от пользователя (20 минут)

### Шаг 1. Создать файл `08_input.sh`

```bash
nano 08_input.sh
```

```bash
#!/bin/bash
# Спрашиваем числа у пользователя

# read -p "подсказка" имя_переменной
# -p — печатает подсказку перед вводом
read -p "Введите первое число: " a
read -p "Введите второе число: " b

# Внимание: read возвращает СТРОКУ.
# Для математики bash сам преобразует в число, но лучше проверять.
sum=$((a + b))
diff=$((a - b))
prod=$((a * b))

echo "---"
echo "Сумма: $sum"
echo "Разность: $diff"
echo "Произведение: $prod"

# Деление — аккуратно, если b = 0
if [ "$b" -ne 0 ]; then
    echo "Деление: $((a / b))"
    echo "Остаток: $((a % b))"
else
    echo "Деление на ноль невозможно"
fi
```

**Сохранить:** `Ctrl+O`, `Enter`, `Ctrl+X`.

### Шаг 2. Запустить

```bash
chmod +x 08_input.sh
./08_input.sh
```

**Пример работы:**
```
Введите первое число: 17

---

Разность: 12
Произведение: 85
Деление: 3
Остаток: 2
```

### Шаг 3. Разбор ключевых моментов

- `read -p "подсказка: " a` — ждёт ввода, кладёт значение в переменную `a`.
- `if [ "$b" -ne 0 ]; then` — проверка «b не равно нулю».
  - `[ ... ]` — команда `test` (проверка условия).
  - `-ne` — **n**ot **e**qual, «не равно». Для чисел используются `-eq`, `-ne`, `-lt`, `-gt`, `-le`, `-ge`.
  - Пробелы внутри `[ ]` **обязательны**.
- `then` — начало блока «если истина».
- `else` — блок «иначе».
- `fi` — **конец** `if` (if наоборот).

> ⚠️ **Почему `"$b"`, а не `$b`?** Если пользователь введёт пустую строку, `[ -ne 0 ]` сломается. Кавычки превращают пустоту в `""` — корректный аргумент.

### Шаг 4. Простой калькулятор

Создайте `09_calc.sh` (`nano 09_calc.sh`):

```bash
#!/bin/bash
# Простой калькулятор

read -p "Первое число: " a
read -p "Второе число: " b
read -p "Операция (+, -, *, /): " op

# case — как "switch" в других языках
# Сравнивает $op с шаблонами
case "$op" in
    +)
        echo "$a + $b = $((a + b))"
        ;;
    -)
        echo "$a - $b = $((a - b))"
        ;;
    \*)
        # Звёздочку нужно экранировать, иначе это шаблон "всё подряд"
        echo "$a * $b = $((a * b))"
        ;;
    /)
        if [ "$b" -ne 0 ]; then
            echo "$a / $b = $((a / b))"
        else
            echo "Ошибка: деление на ноль"
        fi
        ;;
    *)
        # * — совпадает с чем угодно (значение по умолчанию)
        echo "Неизвестная операция: $op"
        ;;
esac
```

**Сохранить:** `Ctrl+O`, `Enter`, `Ctrl+X`.

### Шаг 5. Запустить

```bash
chmod +x 09_calc.sh
./09_calc.sh
```

**Пример работы:**
```
Первое число: 10
Второе число: 3
Операция (+, -, *, /): *
10 * 3 = 30
```

**Разбор `case`:**
- `case "$op" in` — начинаем сравнение.
- `шаблон)` — если `$op` совпал с шаблоном, выполняется код до `;;`.
- `;;` — конец ветки (как `break` в других языках).
- `*)` — «всё остальное» (аналог `default`).
- `esac` — **конец** `case` (case наоборот).

### Пример 1. Расчёт скидки

Создайте `10_discount.sh` (`nano 10_discount.sh`):

```bash
# Расчёт цены со скидкой
```

### Пример 2. Перевод секунд

Создайте `11_time.sh` (`nano 11_time.sh`):

```bash
#!/bin/bash
# Перевод секунд в часы, минуты, секунды

read -p "Введите количество секунд: " total

# 3661 секунда = 1 час, 1 минута, 1 секунда
hours=$((total / 3600))            # сколько часов
remainder=$((total % 3600))        # что осталось после часов
minutes=$((remainder / 60))        # сколько минут
seconds=$((remainder % 60))        # что осталось после минут

echo "---"
echo "$total секунд = $hours ч $minutes мин $seconds с"
```

**Сохранить:** `Ctrl+O`, `Enter`, `Ctrl+X`.

**Разбор алгоритма:**
1. Делим на 3600 (секунд в часе) → получаем часы.
2. Остаток от деления на 3600 → «хвост» меньше часа.
3. Делим этот хвост на 60 → минуты.
4. Остаток от деления на 60 → секунды.

### Пример 3. Сумма чисел от 1 до N

Создайте `12_sum_range.sh` (`nano 12_sum_range.sh`):

```bash
#!/bin/bash
# Считаем сумму чисел от 1 до N

read -p "Введите N: " n

sum=0                    # начальное значение счётчика
i=1                      # счётчик цикла

# while — цикл «пока условие истинно»
# [ $i -le $n ] — «i меньше или равно n»
while [ "$i" -le "$n" ]; do
    sum=$((sum + i))     # добавляем i к сумме
    i=$((i + 1))         # увеличиваем i на 1
done

echo "Сумма чисел от 1 до $n = $sum"
```

**Сохранить:** `Ctrl+O`, `Enter`, `Ctrl+X`.

**Разбор цикла:**
- `while [ условие ]; do` — начало цикла.
- Тело цикла между `do` и `done`.
- `done` — конец цикла.

**Проверка:** `N = 10` → сумма = 55. Формула: `10 * 11 / 2 = 55`.

**Задание 7.** Измените скрипт, чтобы он считал **произведение** чисел от 1 до N (факториал). Подсказка: `prod=1` в начале, `prod=$((prod * i))`.

## Часть 6. Числа с плавающей точкой через `bc` (10 минут)

Bash **не умеет** считать дробные числа: `$((10 / 3))` даст `3`, а не `3.33`.

Для дробных используйте `bc`:

```bash
echo "scale=2; 10 / 3" | bc
```

- `scale=2` — сколько знаков после запятой.
- Результат: `3.33`.

### Создайте `13_float.sh` (`nano 13_float.sh`)

```bash
#!/bin/bash
# Дробные вычисления через bc

read -p "Радиус: " r

# Площадь круга = π × r²
area=$(echo "scale=2; 3.14159 * $r * $r" | bc)

echo "---"
echo "Радиус: $r"
echo "Площадь круга: $area"
```

**Сохранить:** `Ctrl+O`, `Enter`, `Ctrl+X`.

**Разбор:**
- `$(...)` — подстановка команды (в отличие от `$(( ))` для арифметики).
- `| bc` — передать выражение команде `bc`.
- `scale=2` — округление до 2 знаков.

- считает среднее через `bc` с `scale=2`;

## Частые проблемы

| Проблема | Причина | Решение |
|---|---|---|
| `a: command not found` | Пробелы вокруг `=` | `a=10`, не `a = 10` |
| `Permission denied` | Нет права на выполнение | `chmod +x file.sh` |
| `command not found` при `./file.sh` | Нет `./` | Запускать `./file.sh` |
| `syntax error near unexpected token` | Проблема с пробелами или кавычками | Проверьте `[ ]`, `$(( ))` |
| `integer expression expected` | Строка вместо числа | Пользователь ввёл не число |
| `division by 0` | Деление на ноль | Добавьте `if [ "$b" -ne 0 ]` |
| Дроби не считаются | bash — только целые | Используйте `bc` |
| Потеряли код после выхода из nano | Нажали `Ctrl+X` без `Ctrl+O` | Всегда: `Ctrl+O`, `Enter`, `Ctrl+X` |

## Часть 5. Комплексное задание (15 минут)

### Создание мини-проекта

Создайте скрипт `myfirstscript.sh`, который будет выполнять следующие действия:

```bash
#!/bin/bash
# Мой первый скрипт

# 1. Показать текущую дату и время
echo "=== Текущая дата и время ==="
date

# 2. Показать текущую директорию и её содержимое
echo "=== Текущая директория ==="
pwd
ls -la

# 3. Создать папку для логов
mkdir -p logs

# 4. Записать информацию в лог
echo "Дата: $(date)" > logs/info.log
echo "Пользователь: $(whoami)" >> logs/info.log
echo "Система: $(uname -a)" >> logs/info.log

# 5. Показать содержимое лога
echo "=== Содержимое лога ==="
cat logs/info.log

# 6. Проверить сеть
echo "=== Проверка сети ==="
ping -c 2 8.8.8.8 > /dev/null 2>&1
if [ $? -eq 0 ]; then
    echo "Сеть доступна"
else
    echo "Сеть недоступна"
fi

# 7. Показать свободное место на диске
echo "=== Свободное место ==="
df -h /home

echo "=== Готово! ==="
```

**Создайте и запустите этот скрипт:**

```bash
# Создайте файл
nano myfirstscript.sh
# Вставьте код выше

# Сделайте исполняемым
chmod +x myfirstscript.sh

# Запустите
./myfirstscript.sh
```

## Шпаргалка по командам

| Команда | Пример | Описание |
|---------|--------|----------|
| `ls` | `ls -la` | Показать все файлы с деталями |
| `cd` | `cd /home` | Перейти в директорию |
| `pwd` | `pwd` | Показать текущий путь |
| `mkdir` | `mkdir newdir` | Создать папку |
| `rm` | `rm -rf file` | Удалить файл/папку |
| `cp` | `cp file1 file2` | Копировать файл |
| `mv` | `mv file1 dir/` | Переместить файл |
| `cat` | `cat file.txt` | Показать содержимое |
| `grep` | `grep "text" file` | Поиск в тексте |
| `find` | `find . -name "*.txt"` | Поиск файлов |
| `ping` | `ping google.com` | Проверка сети |
| `curl` | `curl -O url` | Запрос к интернету |
| `ss` | `ss -tuln` | Сетевые соединения |
| `chmod` | `chmod +x script.sh` | Изменить права |
| `date` | `date` | Показать дату |

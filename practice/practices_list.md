# Основы написания веб-приложения на Python с SQLite

### 📋 Список практических работ для освоения основ написания веб-приложения на Python с SQLite.

#### Практическая работа №1: Инициализация базы данных SQLite

**Цель:** Научиться создавать файл базы данных и таблицу, понять, где физически хранятся данные.

**Схема работы:**
Скрипт Python → Модуль `sqlite3` → Файл `app.db` (на диске).

**Последовательность транзакций (ключевой момент):**
1.  **Подключение:** `conn = sqlite3.connect('app.db')` — создаёт соединение (или создаёт файл, если его нет).
2.  **Создание курсора:** `cursor = conn.cursor()` — объект для выполнения SQL-запросов.
3.  **Выполнение DDL:** `cursor.execute("CREATE TABLE IF NOT EXISTS items (id INTEGER PRIMARY KEY, name TEXT)")` — создание структуры таблицы.
4.  **Фиксация (Commit):** `conn.commit()` — **критически важный шаг**. Без него изменения (создание таблицы) не будут записаны в файл базы данных навсегда.
5.  **Закрытие:** `conn.close()`.

**Что сделать:**
Написать скрипт `init_db.py`, который создаёт базу и таблицу для сущности «Задача» (id, title, status).

#### Практическая работа №2: Базовые CRUD-операции через консоль

**Цель:** Отработать вставку (INSERT), чтение (SELECT), обновление (UPDATE) и удаление (DELETE) данных, не отвлекаясь на веб-интерфейс.

**Схема работы:**
Пользователь (консоль) → Python-скрипт → SQL-запросы → SQLite.

**Последовательность транзакций (на примере INSERT):**
1.  Открыть соединение: `conn = sqlite3.connect('app.db')`.
2.  Создать курсор.
3.  Выполнить запрос с параметрами: `cursor.execute("INSERT INTO items (name) VALUES (?)", ("Тестовая задача",))`.
    *   *Важно:* Использование `?` защищает от SQL-инъекций.
4.  **Commit:** `conn.commit()` — запись строки в файл.
5.  Проверка: Выполнить `SELECT * FROM items`, получить результат через `cursor.fetchall()`, вывести в консоль.
6.  Закрыть соединение.

**Что сделать:**
Написать интерактивный скрипт, который спрашивает у пользователя действие (добавить/показать/удалить) и выполняет соответствующую операцию.

#### Практическая работа №3: Подключение Flask и первый маршрут (Hello World)

**Цель:** Понять, как Python-код превращается в веб-страницу.

**Схема работы:**
Браузер → HTTP-запрос → Flask (роутинг) → Функция Python → HTTP-ответ → Браузер.

**Последовательность работы (без БД на этом шаге):**
1.  Установить Flask: `pip install flask`.
2.  Создать файл `app.py`.
3.  Инициализировать приложение: `app = Flask(__name__)`.
4.  Определить маршрут: `@app.route('/')` и функцию, возвращающую строку `"Hello"`.
5.  Запустить сервер: `app.run(debug=True)`.
6.  Открыть в браузере `http://127.0.0.1:5000`.

**Что сделать:**
Добиться, чтобы при заходе на главную страницу выводилось приветствие. Убедиться, что сервер перезагружается автоматически при изменении кода (благодаря `debug=True`).

#### Практическая работа №4: Интеграция Flask и SQLite (Чтение данных)

**Цель:** Научиться передавать данные из базы в HTML-шаблон.

**Схема работы:**
Браузер (GET /) → Flask-функция → SQLite (SELECT) → Список данных → HTML-шаблон (Jinja2) → Браузер.

**Последовательность транзакций:**
1.  В функции обработчике маршрута `/` установить соединение с БД.
2.  Выполнить `SELECT * FROM items`.
3.  Получить строки: `rows = cursor.fetchall()`.
4.  Закрыть соединение (после чтения можно закрывать).
5.  Передать `rows` в шаблон: `return render_template('index.html', items=rows)`.
6.  В HTML использовать цикл Jinja2: `{% for item in items %} ... {% endfor %}`.

**Что сделать:**
Создать папку `templates`, файл `index.html`, вывести список задач из базы на страницу.

#### Практическая работа №5: Интеграция Flask и SQLite (Добавление данных)

**Цель:** Отработать полный цикл: форма → POST-запрос → INSERT → редирект.

**Схема работы:**
Браузер (форма) → POST /add → Flask → SQLite (INSERT + Commit) → Редирект на главную (GET /).

**Последовательность транзакций:**
1.  В шаблоне создать `<form method="POST" action="/add">` с полем ввода.
2.  В `app.py` создать маршрут `@app.route('/add', methods=['POST'])`.
3.  Получить данные из формы: `request.form['title']`.
4.  Открыть соединение с БД.
5.  Выполнить `INSERT` с параметрами.
6.  **Commit:** `conn.commit()` — без этого данные не сохранятся.
7.  Закрыть соединение.
8.  Вернуть `redirect('/')`, чтобы пользователь не отправлял форму повторно при обновлении страницы.

**Что сделать:**
Реализовать добавление новой записи через веб-форму и убедиться, что она появляется в списке на главной странице.

#### Практическая работа №6: Обработка ошибок и защита соединений

**Цель:** Научиться правильно закрывать соединения даже при ошибках, чтобы не блокировать базу данных.

**Схема работы:**
Попытка операции → Успех/Ошибка → Блок `finally` → Гарантированное закрытие соединения.

**Последовательность (правильный паттерн):**
```python
conn = sqlite3.connect('app.db')
try:
    # выполнение запросов
    conn.commit()
except sqlite3.Error as e:
    # обработка ошибки
    conn.rollback()  # откат транзакции при ошибке
finally:
    conn.close()     # закрытие в любом случае
```
**Что сделать:**
Обернуть операции с БД в конструкции `try...except...finally`. Специально вызвать ошибку (например, вставить `NULL` в колонку `NOT NULL`) и убедиться, что приложение не падает, а соединение корректно закрывается.

### 💡 Ключевые моменты для запоминания

1.  **Commit — это запись на диск.** `INSERT` без `commit()` живёт только в памяти программы и исчезает при закрытии соединения.
2.  **SQLite не требует сервера.** База — это один файл. Если вы видите файл `.db` в папке проекта, значит, данные там.
3.  **Flask и SQLite — разные вещи.** Flask не управляет базой. Вы сами открываете и закрываете соединение в каждой функции-обработчике маршрута.
4.  **Параметризованные запросы обязательны.** Всегда используйте `?` в SQL и передавайте значения кортежем вторым аргументом в `execute()`.

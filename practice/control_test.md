Выбери **один** правильный вариант. За каждый верный ответ — **1 балл**.

**1. Что произойдёт, если после `cursor.execute("INSERT ...")` не вызвать `conn.commit()`?**
- а) Данные сохранятся, но только после закрытия программы
- б) Данные не будут записаны на диск и пропадут при закрытии соединения
- в) Python выдаст ошибку `ProgrammingError`
- г) Данные запишутся, но в другую таблицу

**2. Какой из запросов защищён от SQL-инъекции?**
- а) `cursor.execute(f"INSERT INTO tasks (title) VALUES ('{title}')")`
- б) `cursor.execute("INSERT INTO tasks (title) VALUES ('" + title + "')")`
- в) `cursor.execute("INSERT INTO tasks (title) VALUES (?)", (title,))`
- г) `cursor.execute("INSERT INTO tasks (title) VALUES (%s)" % title)`

**3. Что вернёт `cursor.fetchall()`, если в таблице нет строк?**
- а) `None`
- б) `[]` (пустой список)
- в) `0`
- г) Выбросит исключение

**4. Какой HTTP-метод нужно использовать для отправки формы, которая создаёт новую запись в базе?**
- а) GET
- б) POST
- в) PUT
- г) HEAD

**5. Что делает `redirect(url_for('index'))` после успешного POST?**
- а) Открывает новую вкладку в браузере
- б) Отправляет браузеру команду перейти на GET `/`
- в) Выполняет функцию `index()` повторно
- г) Сохраняет данные в базу

**6. Зачем нужен `finally: conn.close()` в конструкции `try/except/finally`?**
- а) Чтобы ускорить выполнение запроса
- б) Чтобы соединение закрылось при любом исходе — даже при ошибке
- в) Чтобы записать данные на диск
- г) Чтобы отменить транзакцию

**7. Что делает `conn.rollback()`?**
- а) Закрывает соединение
- б) Создаёт резервную копию базы
- в) Отменяет текущую транзакцию — изменения не попадут в базу
- г) Возвращает последний `SELECT`

**8. Что означает запись `@app.route('/delete/<int:task_id>', methods=['POST'])`?**
- а) Маршрут принимает только POST; `task_id` — целое число из URL
- б) Маршрут принимает GET и POST; `task_id` — строка
- в) Маршрут удаляет запись по имени `task_id`
- г) Маршрут доступен только администратору

**9. Что такое `sqlite3.Row`?**
- а) Название таблицы в базе
- б) Обёртка над строкой результата, позволяющая обращаться к полям по имени: `row['title']`
- в) Функция для создания новой строки в таблице
- г) Тип данных для хранения денег

**10. Что произойдёт, если открыть `/toggle/5` в адресной строке браузера, а маршрут объявлен с `methods=['POST']`?**
- а) Задача переключится
- б) Браузер вернёт 404
- в) Браузер вернёт 405 Method Not Allowed
- г) Flask автоматически выполнит POST

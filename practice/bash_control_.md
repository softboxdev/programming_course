# 📝 ПРОВЕРОЧНАЯ РАБОТА ПО BASH

**Инструкция:** Выполните задания, используя терминал Linux и текстовый редактор (nano, vim или любой другой). Создавайте `.sh` файлы, давайте им права на выполнение и запускайте.
Решение в виде файла МосТех.Документы - отчета с принтскринами собранного файла в командной строке, сохраненного в вашей рабочей папке.

## ЗАДАНИЕ 1: ПРИВЕТСТВИЕ (5 баллов)

Создайте скрипт `greeting.sh`, который:
1. Спрашивает у пользователя его ФИО
2. Выводит приветствие: `"Привет, <имя>! Добро пожаловать в мир Bash!"`

**Пример работы:**
```
$ ./greeting.sh
Введите ваше ФИО_ГРУППА: Анна
Привет, Анна! Добро пожаловать в мир Bash!
```

## ЗАДАНИЕ 2: КАЛЬКУЛЯТОР (7 баллов)

Создайте скрипт `calculator.sh`, который:
1. Запрашивает у пользователя два числа
2. Запрашивает операцию (`+`, `-`, `*`, `/`)
3. Выводит результат вычисления


**Пример работы:**
```
$ ./calculator.sh
Введите первое число: 10
Введите второе число: 5
Введите операцию (+, -, *, /): *
Результат: 10 * 5 = 50
```

## ЗАДАНИЕ 3: ПРОВЕРКА ЧИСЛА (6 баллов)

Создайте скрипт `check_number.sh`, который:
1. Принимает число как аргумент командной строки (например, `./check_number.sh 7`)
2. Проверяет, является ли число:
   - Положительным
   - Отрицательным
   - Нулём

**Подсказка:** Используйте `$1` для доступа к первому аргументу.

**Пример работы:**
```
$ ./check_number.sh -5
Число -5 является отрицательным

$ ./check_number.sh 0
Число 0 является нулём
```

## ЗАДАНИЕ 4: СПИСОК ФАЙЛОВ (7 баллов)

Создайте скрипт `list_files.sh`, который:
1. Принимает путь к директории как аргумент командной строки
2. Проверяет, существует ли директория
3. Если существует — выводит список всех `.txt` файлов в ней с указанием их размера
4. Если не существует — выводит сообщение об ошибке

**Подсказки:**
- `-d` — проверка существования директории
- `-f` — проверка, что это файл
- `du -h` или `ls -lh` для размера файла

**Пример работы:**
```
$ ./list_files.sh /home/user/documents
Найдены .txt файлы в /home/user/documents:
- file1.txt (1.2K)
- notes.txt (4.5K)
```

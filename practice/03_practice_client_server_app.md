# Практическая работа №3: Подключение Flask и первый маршрут (Hello World)

## 📚 Теоретическая справка

### Что такое Flask и зачем он нужен

До этого момента наши скрипты работали в **консоли**: пользователь запускал `python crud_console.py`, вводил команды, получал текст в терминале. Это удобно для обучения, но настоящее веб-приложение работает иначе.

**Flask** — это микрофреймворк для Python, который превращает твой Python-код в **веб-сервер**. Схема работы:

```
Браузер (клиент)  →  HTTP-запрос  →  Flask  →  Python-функция  →  HTTP-ответ  →  Браузер
```

Flask слушает определённый **порт** (обычно 5000), принимает запросы от браузера, вызывает нужную Python-функцию и возвращает ответ (HTML-страницу, JSON, редирект).

### Ключевые понятия Flask

**Маршрут (route)** — правило: «если браузер запросил такой-то URL, выполни такую-то функцию». В коде маршрут задаётся декоратором `@app.route(...)`.

**Декоратор** — это «обёртка» над функцией. Синтаксис `@app.route('/')` перед функцией означает: «Flask, запомни эту функцию и вызывай её, когда придёт запрос на URL `/`».

**Представление (view function)** — сама функция-обработчик маршрута. Она должна вернуть то, что увидит браузер: строку, HTML-шаблон или редирект.

**HTTP-методы** — тип запроса. Основные:
- `GET` — «дай мне страницу» (когда ты открываешь URL в браузере).
- `POST` — «отправь данные на сервер» (когда отправляешь форму).

По умолчанию маршрут принимает только `GET`. Чтобы принимать `POST`, нужно указать `methods=['GET', 'POST']`.

### Что такое localhost и порт

Когда ты запускаешь Flask, сервер поднимается на твоём компьютере. Адрес `http://127.0.0.1:5000` означает:
- `127.0.0.1` — **localhost**, твой собственный компьютер.
- `5000` — **порт**, «дверь», через которую сервер слушает запросы.

Другой человек с другого компьютера не сможет открыть этот адрес — сервер работает только локально. Это нормально для разработки.

### Почему `debug=True`

Режим отладки (`debug=True`) даёт два важных бонуса:
1. **Автоперезагрузка** — при сохранении файла сервер сам перезапускается, тебе не нужно каждый раз останавливать и запускать его заново.
2. **Подробные ошибки в браузере** — если в коде ошибка, Flask покажет трассировку прямо на странице.

> ⚠️ **Важно:** `debug=True` **нельзя** использовать на реальном сервере в интернете — это угроза безопасности. Только для разработки.

## 🎯 Пошаговая инструкция

### Шаг 1. Установка Flask

Открой терминал в папке проекта (`task_manager`) и выполни:

```bash
pip install flask
```

Проверь установку:

```bash
pip show flask
```

Ты увидишь версию (например, 3.x). Если команда `pip` не находится — попробуй `pip3` или `python -m pip install flask`.

### Шаг 2. Структура проекта

После установки Flask создадим структуру папок. Flask имеет **соглашение об именах**: HTML-файлы должны лежать в папке `templates/` рядом с основным скриптом. Иначе Flask их не найдёт.

```
task_manager/
├── init_db.py
├── check_db.py
├── crud_console.py
├── app.db
├── app.py              ← новый файл (Flask-приложение)
└── templates/          ← новая папка (пока пустая)
```

Создай папку `templates` и пустой файл `app.py`.

> **Почему `templates` именно так:** имя папки зашито во Flask. Если назовёшь её `html` или `views` — шаблоны не найдутся, и ты получишь ошибку `TemplateNotFound`.

### Шаг 3. Первый маршрут — «Hello, Flask!»

Открой `app.py` и внеси минимальный код:

```python
from flask import Flask

# Создаём приложение. __name__ — имя текущего модуля;
# Flask использует его, чтобы найти папку templates рядом с файлом.
app = Flask(__name__)


@app.route('/')
def index():
    """Главная страница. Возвращает строку — браузер покажет её как текст."""
    return "Hello, Flask!"


if __name__ == '__main__':
    # debug=True — автоперезагрузка + подробные ошибки
    # port=5000 — стандартный порт Flask
    app.run(debug=True, port=5000)
```

### Шаг 4. Запуск сервера

В терминале, находясь в папке `task_manager`, выполни:

```bash
python app.py
```

Ты увидишь примерно такой вывод:

```
 * Serving Flask app 'app'
 * Debug mode: on
 * Running on http://127.0.0.1:5000
 * Debugger is active!
 * Debugger PIN: 123-456-789
```

**Не закрывай терминал** — сервер работает, пока терминал открыт. Чтобы остановить — нажми `Ctrl+C`.

### Шаг 5. Открытие в браузере

Открой браузер и введи в адресную строку:

```
http://127.0.0.1:5000
```

Ты увидишь текст **Hello, Flask!**.

**Что произошло по шагам:**
1. Браузер отправил `GET /` на `127.0.0.1:5000`.
2. Flask получил запрос, нашёл маршрут `/` и вызвал функцию `index()`.
3. Функция вернула строку `"Hello, Flask!"`.
4. Flask обернул строку в HTTP-ответ с кодом 200 (OK) и отправил браузеру.
5. Браузер отрисовал текст.

### Шаг 6. Проверка автоперезагрузки

Не останавливая сервер, измени строку:

```python
return "Hello, Flask! Я работаю."
```

Сохрани файл (`Ctrl+S`). В терминале появится:

```
 * Detected change in 'app.py', reloading
 * Restarting with stat
```

Обнови страницу в браузере (`F5`) — увидишь новый текст. **Это и есть debug-режим в действии:** сервер сам перезагрузил код, тебе не пришлось ничего перезапускать.

### Шаг 7. Второй маршрут — добавление страницы

Добавим ещё один маршрут — страницу «О проекте». В `app.py` после функции `index()` добавь:

```python
@app.route('/about')
def about():
    return "Это учебный список задач на Flask. Практическая работа №3."
```

Сохрани файл. Обнови браузер на `http://127.0.0.1:5000/about` — увидишь новый текст.

Обрати внимание: **каждому URL соответствует своя функция**. Flask сопоставляет URL с маршрутом и вызывает нужную функцию.

### Шаг 8. Проверка обработки ошибок 404

Открой в браузере несуществующий адрес:

```
http://127.0.0.1:5000/nonexistent
```

Ты увидишь страницу **404 Not Found**. Это стандартный ответ Flask: маршрут не найден. Значит, сервер работает корректно и различает существующие и несуществующие адреса.

### Шаг 9. Возврат HTML-строки (первое приближение к веб-странице)

Строка `"Hello, Flask!"` — это просто текст. Но Flask может вернуть и HTML. Измени функцию `index()`:

```python
@app.route('/')
def index():
    return """
    <html>
        <head><title>Список задач</title></head>
        <body>
            <h1>Мой список задач</h1>
            <p>Скоро здесь будет список задач из базы данных.</p>
        </body>
    </html>
    """
```

Сохрани и обнови страницу — браузер отрисует заголовок и параграф.

**Проблема этого подхода:** смешивать Python-код и HTML в одной строке неудобно. Для реальных страниц используют **шаблоны Jinja2** — отдельные `.html` файлы. Этим займёмся в Практической работе №4.

### Шаг 10. Полный код `app.py` (итог работы №3)

```python
from flask import Flask

app = Flask(__name__)


@app.route('/')
def index():
    return """
    <html>
        <head><title>Список задач</title></head>
        <body>
            <h1>Мой список задач</h1>
            <p>Скоро здесь будет список задач из базы данных.</p>
            <p><a href="/about">О проекте</a></p>
        </body>
    </html>
    """


@app.route('/about')
def about():
    return "Это учебный список задач на Flask. Практическая работа №3."


if __name__ == '__main__':
    app.run(debug=True, port=5000)
```

Проверь оба маршрута (`/` и `/about`) и клик по ссылке «О проекте» — она должна вести на страницу `/about`.

## ⚠️ Типичные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `ModuleNotFoundError: No module named 'flask'` | Flask не установлен | `pip install flask` |
| `Address already in use` (порт 5000 занят) | Другой процесс слушает 5000 | Останови старый сервер (`Ctrl+C`) или смени порт: `port=5001` |
| `TemplateNotFound` (появится в работе №4) | HTML лежит не в `templates/` | Проверь имя папки и её расположение рядом с `app.py` |
| Страница не обновляется | Сервер не в debug-режиме | Убедись, что `debug=True`; перезапусти вручную |
| `404 Not Found` на существующем маршруте | Опечатка в URL или маршруте | Сравни URL в браузере и `@app.route(...)` в коде |
| Изменения в коде не подхватываются | Файл не сохранён | `Ctrl+S` в редакторе |

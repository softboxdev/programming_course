## Краткая справка (повторение перед работой)

**Стек (stack)** — структура данных, работающая по принципу **LIFO** (Last In — First Out): последний добавленный элемент извлекается первым.

**Основные операции:**
- `push(x)` — добавить элемент `x` на вершину стека;
- `pop()` — удалить и вернуть верхний элемент;
- `top()` / `peek()` — посмотреть верхний элемент без удаления;
- `is_empty()` — проверить, пуст ли стек;
- `size()` — количество элементов.

**Реализация в Python через список:**
```python
stack = []          # создание пустого стека
stack.append(5)     # push: добавить 5
stack.append(10)    # push: добавить 10
top = stack[-1]     # top: посмотреть верхний (10)
x = stack.pop()     # pop: извлечь верхний (10)
empty = len(stack) == 0  # is_empty
```

**Модуль `collections.deque`** — более быстрая альтернатива для стека и очереди:
```python
from collections import deque
stack = deque()
stack.append(5)
x = stack.pop()
```

### Задание 11 (5 баллов)

Правильные ошибки (достаточно любых трёх из списка):

1. **Второй аргумент `execute` — не кортеж.** `title` передано строкой. Нужно `(title,)` с запятой. Иначе `sqlite3.ProgrammingError: Incorrect number of bindings`. — **1 балл**
2. **Нет `conn.commit()`** после INSERT. Данные не запишутся на диск. — **1 балл**
3. **Нет `conn.close()`** — соединение останется открытым, файл может залочиться. — **1 балл**
4. **Нет `try/except/finally`** — при любой ошибке соединение не закроется, `rollback` не выполнится. — **1 балл**
5. (Бонус) **Нет обработки ошибок** — `execute` может выбросить исключение наружу. — **до 1 балла**

Максимум — **5 баллов** (засчитываются первые три верные ошибки + до 2 бонусных с обоснованием).

### Задание 12 (7 баллов)

Эталонное решение:

```python
def delete_task_by_id(task_id):
    conn = sqlite3.connect('app.db')
    try:
        cursor = conn.cursor()
        cursor.execute("DELETE FROM tasks WHERE id = ?", (task_id,))
        conn.commit()
        return cursor.rowcount
    except sqlite3.Error as e:
        conn.rollback()
        print(f"[DB ERROR] {e}")
        return 0
    finally:
        conn.close()
```

**Распределение баллов:**

| Критерий | Балл |
|---|---|
| `conn = sqlite3.connect('app.db')` **до** `try` | 1 |
| `DELETE FROM tasks WHERE id = ?` с `(task_id,)` | 2 |
| `conn.commit()` после `execute` | 1 |
| `try/except/finally` присутствует | 1 |
| `conn.rollback()` в `except` | 1 |
| `return cursor.rowcount` (до закрытия соединения) и `return 0` при ошибке | 1 |

Максимум — **7 баллов**. Снижение на 1 балл за: f-строку вместо `?`; `commit` после `close`; отсутствие `finally`.

### Задание 13 (8 баллов)

Эталонная последовательность:

3. **Маршрут** проверяет `request.method == 'POST'`, читает `title = request.form.get('title', '').strip()`. — 1 балл

5. **Открытие соединения:** `conn = sqlite3.connect('app.db')`. — 1 балл

7. **Фиксация:** `conn.commit()` — данные записаны на диск. При ошибке — `rollback()` в `except`. — 1 балл
8. **Закрытие:** `finally: conn.close()`. — 1 балл
9. **Редирект:** `return redirect(url_for('index'))` → браузер делает GET `/`, видит список с новой задачей (PRG-паттерн). — 1 балл

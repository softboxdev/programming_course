### Задача B1. Вычислительные операции (4 балла)

**Условие:** Пользователь вводит три целых числа `a`, `b`, `c`. Выведите:
- сумму `a + b + c`;
- произведение `a * b * c`;
- среднее арифметическое (вещественное число);
- остаток от деления `a` на `b`.

**Пример ввода:**
```
10
3
5
```

**Пример вывода:**
```
Сумма: 18
Произведение: 150
Среднее: 6.0
Остаток: 1
```

**Подсказка:** используйте `int(input())` для ввода и `print()` для вывода.

### Задача B5. Запуск скрипта и вычисления (4 балла)

**Условие:** Напишите программу, которая:
- запрашивает у пользователя радиус круга `r` (вещественное число);
- вычисляет длину окружности `L = 2 * π * r` и площадь круга `S = π * r²`;
- выводит результаты с точностью до 2 знаков после запятой.

**Подсказка:** `π = 3.14159`, для округления используйте `round(число, 2)`.

**Пример ввода:**
```
5
```

**Пример вывода:**
```
Длина окружности: 31.42
Площадь круга: 78.54
```

### Задача C1. Мини-проект «Статистика оценок»

**Условие:** Напишите программу, которая:
1. Запрашивает у пользователя количество учеников `n`.
2. Для каждого ученика вводит имя и оценку (от 2 до 5).
3. Сохраняет данные в **список кортежей** вида `(имя, оценка)`.
4. Выводит:
   - список всех учеников с оценками;
   - средний балл класса;
   - имя ученика с максимальной оценкой;
   - количество отличников (оценка 5);
   - количество двоечников (оценка 2).

**Пример работы:**
```
Введите количество учеников: 4
Имя: Анна
Оценка: 5
Имя: Борис
Оценка: 3
Имя: Виктор
Оценка: 5
Имя: Галина
Оценка: 2

Список учеников:
  Анна: 5
  Борис: 3
  Виктор: 5
  Галина: 2
Средний балл: 3.75
Лучший ученик: Анна
Отличников: 2
Двоечников: 1
```

**Подсказка:** используйте `for` для ввода, `append` для добавления в список, `sum` и `max` для вычислений.

### Задача C2 (альтернатива). Мини-проект «Корзина покупок»

**Условие:** Напишите программу, которая:
1. Создаёт список кортежей — товары `(название, цена, количество)`:
   ```python
   cart = [("Хлеб", 40, 2), ("Молоко", 80, 1), ("Сыр", 250, 1)]
   ```
2. Выводит каждый товар в формате: `Хлеб — 40 руб. × 2 = 80 руб.`
3. Считает итоговую сумму покупки.
4. Находит самый дорогой товар (по цене за единицу).
5. Выводит итог.

**Пример вывода:**
```
Хлеб — 40 руб. × 2 = 80 руб.
Молоко — 80 руб. × 1 = 80 руб.
Сыр — 250 руб. × 1 = 250 руб.
Итого: 410 руб.
Самый дорогой: Сыр (250 руб.)
```

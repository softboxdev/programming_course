## Пояснения к сложным вопросам

**Вопрос 5:** Клиентский код не имеет прямого доступа к базе данных. Методы записи (`Записать()`, `Удалить()`) доступны только в серверном контексте. Попытка вызова приведет к ошибке компиляции или выполнения.

**Вопрос 15:** Условие в параметрах виртуальной таблицы позволяет платформе рассчитать остатки сразу с нужным отбором, не вычисляя их по всей базе. Условие в `ГДЕ` применяется после расчета, что значительно медленнее на больших объемах данных.

**Вопрос 19:** Параметр объявлен с ключевым словом `Знач`, поэтому передается копия значения. Изменение внутри процедуры не влияет на исходную переменную. Результат — 5.

**Вопрос 20:** Параметр передан по ссылке (по умолчанию). Изменение внутри процедуры изменяет исходную переменную. Результат — 10.

**Вопрос 16:** Язык запросов выполняется на стороне СУБД, которая оптимизирована для быстрой выборки данных. Перебор выборки в цикле на сервере 1С загружает данные построчно и работает медленнее на больших объемах.

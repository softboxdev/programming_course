# Перечень практических работ для студентов на индивидуальном графике для МДК 04.01 Внедрение и поддержка компьютерных систем (ИГ)

Задание: написать по одному проекту самостоятельно изучив темы из модулей ниже.
60 % работ - оценка 3, 80 % работ - оценка 4, 100% работ - оценка 5.
Самостоятельная подготовка к экзамену https://bom.firpo.ru/Public/6397

---

### 1. Понимание структуры экзамена

Экзамен длится **3 часа 30 минут** (для базового уровня) или **4 часа** (для профильного). Он состоит из четырех заданий, которые проверяют ваши профессиональные компетенции (ПК).

**Ваши основные задачи:**
1.  **Задание 1 (Базы данных):** Разработка и администрирование БД.
2.  **Задание 2 (Модули ПО):** Разработка алгоритма и кода приложения.
3.  **Задание 3 (Сопровождение ПО):** Модификация компонентов ПО (доступно только для профильного уровня).
4.  **Задание 4 (Интеграция):** Интеграция модулей и использование системы контроля версий (доступно только для профильного уровня).

---

### 2. Подготовка по каждому модулю

#### Модуль 1: Разработка, администрирование и защита баз данных
**Что нужно уметь:**
*   Проектировать базу данных в **третьей нормальной форме (3НФ)**.
*   Создавать ER-диаграммы (в формате PDF).
*   Работать с СУБД (создание таблиц, ключей, ограничений).
*   Импортировать данные из предоставленных файлов (Excel/CSV).
*   Сохранять результаты в виде SQL-скрипта или файла конфигурации `.dt` для 1С.

**План подготовки:**
1.  **Проектирование:** Повторите тему нормализации. Убедитесь, что вы можете на бумаге или в программе (например, draw.io, dbdiagram.io) нарисовать схему БД для предметной области «Продажа обуви».
2.  **СУБД:** Выберите одну СУБД (PostgreSQL, MySQL, MS SQL) и доведите до автоматизма:
    *   Написание `CREATE TABLE` с правильными типами данных.
    *   Настройка `PRIMARY KEY` и `FOREIGN KEY` с каскадным обновлением/удалением.
    *   Написание `INSERT INTO` для загрузки данных.
3.  **Импорт:** Отработайте навык импорта данных из Excel/CSV в вашу СУБД (через командную строку, pgAdmin, MySQL Workbench или SSMS).
4.  **1С (если применимо):** Если вы сдаете на 1С, обязательно изучите, как выгружать базу в файл `.dt` и как загружать данные из таблиц.

#### Модуль 2: Разработка модулей программного обеспечения
**Что нужно уметь:**
*   Разрабатывать алгоритм (блок-схема или псевдокод).
*   Писать код на выбранном языке (C#, Java, Python, 1С).
*   Реализовывать расчет цены с учетом скидки (25%, если не было заказов в прошлом месяце).
*   Создавать графический интерфейс по макету (каталог товаров).
*   Выполнять отладку и тестирование.

**План подготовки:**
1.  **Алгоритмы:** Повторите построение блок-схем. Уделите внимание алгоритму расчета скидки (условие: если в прошлом месяце заказов не было, то скидка 25%).
2.  **Язык программирования:** Выберите один язык (Python, C# или Java) и повторите:
    *   Работа с базами данных (подключение, SELECT-запросы).
    *   Обработка исключений (try-catch).
    *   Создание форм/окон.
3.  **Интерфейс:** Изучите макет из задания (стр. 33-34). Вам нужно реализовать вывод карточек товаров с изображением, категорией, названием, производством, составом и ценой.
    *   **Важно:** Реализуйте логику подсветки (светло-красный, если товара ≤ 3) и логику вывода «много»/«мало» (больше 5 или меньше).
4.  **Стиль кода:** Соблюдайте соглашения об именовании (CamelCase для C#/Java, snake_case для Python). Одна команда в строке.

#### Модуль 3: Сопровождение и обслуживание ПО (для профильного уровня)
**Что нужно уметь:**
*   Модифицировать существующий код под требования заказчика.
*   Разрабатывать и настраивать модули.
*   Использовать средства поиска и анализа информации.

**План подготовки:**
*   Практикуйтесь в рефакторинге кода. Учитесь быстро находить нужный фрагмент в чужом коде и вносить изменения, не ломая остальную логику.
*   Повторите работу с системами контроля версий (Git) для поиска информации об изменениях.

#### Модуль 4: Интеграция программных модулей (для профильного уровня)
**Что нужно уметь:**
*   Использовать систему контроля версий (Git).
*   Интегрировать модули в единое ПО.
*   Оформлять README.md.

**План подготовки:**
1.  **Git:** Отработайте следующие команды: `git init`, `git add`, `git commit`, `git push`, `git pull`, `git branch`, `git merge`.
2.  **Интеграция:** Поймите, как связать ваш код (Задание 2) с базой данных (Задание 1) в единое приложение.
3.  **Документация:** Научитесь писать понятный `README.md` с описанием функционала системы.

### 3. Модуль 5: Практическая отработка (Сценарий экзамена)

Вам дана предметная область: **«Компания по продаже обуви»**. Вот примерный план ваших действий на экзамене:

**Шаг 1. База данных (50 мин):**
*   Создайте таблицы: `Товары` (модель, размер, количество, цена, изображение), `Заказы` (дата, клиент), `Состав_заказа` (ссылка на товар и заказ, количество).
*   Настройте связи.
*   Загрузите данные из файлов `import`.
*   Сделайте ER-диаграмму и сохраните скрипт.

**Шаг 2. Приложение (40 мин):**
*   Напишите код для вывода каталога.
*   Реализуйте расчет цены: `Цена_со_скидкой = Цена * 0.75`, если в прошлом месяце не было заказов на этот товар.
*   Реализуйте логику «много»/«мало» и подсветку.

**Шаг 3. Доработка (1 час):**
*   Добавьте авторизацию (по логину из списка).
*   Реализуйте сортировку, фильтрацию и поиск.
*   Реализуйте корзину и оформление заказа.
*   Добавьте интерфейс для Администратора и Менеджера (работа с заказами).

**Шаг 4. Финализация (1 час):**
*   Загрузите код в Git-репозиторий.
*   Создайте `README.md`.
*   Проверьте работоспособность приложения.
